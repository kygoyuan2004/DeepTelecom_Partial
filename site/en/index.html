Turning scattered UAV propagation simulations into one reproducible dataset.

Three compute environments produced a large collection of distributed ray-tracing outputs. We inventoried them read-only, removed physical copies, audited ID conflicts, assigned one public namespace, packaged a standard sample contract, and verified every shard—yielding 44,988 traceable samples.

What we did

More than uploading files:
we built an auditable data path.

The public dataset is no longer divided by compute device. Source provenance remains in the manifest, while every sample shares one ID and shard namespace.

  1. 01

    Read-only inventory

    Scanned three compute environments and froze file, status, class, size, and hash inventories.

  2. 02

    Curation decisions

    Separated formal samples from local copies, incomplete outputs, test runs, and invalid files.

  3. 03

    Global audit

    Deduplicated by content hash and reviewed records that reused an old ID but contained different data.

  4. 04

    One sample contract

    Assigned continuous public IDs and paired every sample as NPZ + PNG + JSON.

  5. 05

    Package and publish

    Built 140 deterministic TARs and verified SHA-256, LFS objects, and the commit chain shard by shard.

Access and usage

Download everything or stream on demand.

These examples pin an immutable commit, so later repository updates cannot silently alter your experiment. Public paths contain no device names, and the release does not impose train, validation, or test splits.

Public layoutUnified namespace
data/v1/shards/
├── shard-00000.tar
├── shard-00001.tar
├── …
└── shard-00139.tar

manifests/v1/all_samples.jsonl.gz
schemas/v1/sample.schema.json
checksums/v1/SHA256SUMS

Use the unified manifest to build task-specific splits. Source devices never appear in public paths or filenames.

Download with Python
from huggingface_hub import snapshot_download

root = snapshot_download(
    repo_id="KYGOYUAN/DeepTelecom_Partial",
    repo_type="dataset",
    revision="de7fc35cb41af3d9c5b2f52dab5483e3ceb623b3",
)
Stream with WebDataset
import webdataset as wds

base = "https://huggingface.co/datasets/KYGOYUAN/DeepTelecom_Partial/resolve/de7fc35cb41af3d9c5b2f52dab5483e3ceb623b3"
urls = base + "/data/v1/shards/shard-{00000..00139}.tar"
samples = wds.WebDataset(urls, shardshuffle=True).decode("pil")
