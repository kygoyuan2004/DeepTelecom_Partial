我们完成了什么

不是简单上传文件，
而是建立一条可复核的数据路径。

公开数据中不再按计算设备分目录。来源只作为 provenance 保留在 manifest 中，所有样本进入同一个编号和分片体系。

  1. 01

    只读清点

    扫描三套计算环境，冻结文件、状态、类别、大小与哈希清单。

  2. 02

    清洗判定

    区分正式样本、本地副本、未完成输出、测试任务和无效文件。

  3. 03

    全局核验

    按内容哈希查重，人工规则复核旧编号相同但内容不同的样本。

  4. 04

    统一格式

    分配连续公开 ID，为每个样本建立 NPZ + PNG + JSON 合同。

  5. 05

    打包发布

    构建 140 个确定性 TAR，逐一验证 SHA-256、LFS 对象和提交链。

获取与使用

完整下载，或者按需流式读取。

示例固定到不可变提交，后续仓库更新不会悄悄改变你的实验。公开目录不含任何设备名称，也不预设训练、验证或测试划分。

公开目录统一命名空间
data/v1/shards/
├── shard-00000.tar
├── shard-00001.tar
├── …
└── shard-00139.tar

manifests/v1/all_samples.jsonl.gz
schemas/v1/sample.schema.json
checksums/v1/SHA256SUMS

可根据任务从统一 manifest 自行构造 split，来源设备不会进入公开路径或文件名。

使用 Python 下载
from huggingface_hub import snapshot_download

root = snapshot_download(
    repo_id="KYGOYUAN/DeepTelecom_Partial",
    repo_type="dataset",
    revision="de7fc35cb41af3d9c5b2f52dab5483e3ceb623b3",
)
使用 WebDataset 流式读取
import webdataset as wds

base = "https://huggingface.co/datasets/KYGOYUAN/DeepTelecom_Partial/resolve/de7fc35cb41af3d9c5b2f52dab5483e3ceb623b3"
urls = base + "/data/v1/shards/shard-{00000..00139}.tar"
samples = wds.WebDataset(urls, shardshuffle=True).decode("pil")
