Format and schema

数据格式与 Schema

所有公开样本都遵循 NPZ + PNG + JSON 的外层协议；NPZ 内部存在两个已登记的张量 schema，读取时必须检查 tensor_schema_id。

记录类型数量说明
dtuav-etoile-32key-v144,948v1 主张量结构，包含 32 个数组键。
dtuav-floor-wall-24key-v140早期正式样本的 24-key 结构；未伪造缺失数组。
JSON sidecar44,988统一记录公开 ID、类别、schema、文件哈希与来源信息。

读取约束

  • 总计 134,964 个 TAR 成员，即每个样本 3 个成员。
  • 当前发布不预设训练集、验证集或测试集。
  • sidecar 与全局 allocation/provenance manifest 是不同记录类型。
  • 来源设备只保留在 provenance，不进入公开目录或文件名。

Generation method

仿真和数据生成方法

公开参考生成器基于 Sionna RT 2.0.1 内置 Étoile 场景。主配置为 28 GHz、20 kHz 和 2,048 个快照。

  1. 01

    类别与轨迹

    读取倾斜角、机体速度、初始状态和直线或 Bézier 路径。

  2. 02

    运动点散射体

    计算机体点、旋翼中心与叶片径向点的位置和速度。

  3. 03

    逐快照射线追踪

    求解基站到各 passive receiver probe 的单程 CIR。

  4. 04

    单站回波与 STFT

    以加权复信道平方的相干和近似往返回波，加入 AWGN 后计算 STFT。

  5. 05

    研究输出与发布

    生成器输出 NPZ、PNG 和运行元数据；正式发布另由 builder 生成 sidecar、TAR 与校验记录。

当前可配置

复制完整配置后，可将 points_per_blade 从 3 调至 5，使标准模型由 25 增至 41 个点；轨迹可选择固定 +x 的直线或单段四控制点三次 Bézier。

当前实现边界

固定一架四旋翼；不支持 waypoint/CSV、多段轨迹或避障规划。新增运动类别需要修改代码并补充测试。模型变化应进入新的实验命名空间。

Curation and integrity

数据质量与可复现性

三套来源环境先完成只读清点，再按内容、状态和发布规则统一核验。不同内容的旧编号冲突样本保留为不同公开 ID。

  1. 01

    只读清点

    冻结文件、类别、大小与哈希清单。

  2. 02

    清洗判定

    识别本地副本、无效、未完成和非正式记录。

  3. 03

    全局核验

    按内容哈希复核重复与旧编号冲突。

  4. 04

    统一编号

    分配连续 ID DTUAV-V1-000001–044988。

  5. 05

    打包校验

    构建并核验 140 个确定性 WebDataset TAR。

Scope and limitations

建模范围与已知限制

  • 数据来源全部来自仿真，不是无人机实飞采集或测量 ground truth。
  • 电磁模型运动点散射体单基地回波近似，不是物理网格、标定 RCS 或全波求解。
  • 张量结构44,948 个样本为 32-key，40 个早期样本为 24-key；不能假定内部字段完全相同。
  • 数据划分v1.0.0 没有预设 train、validation 或 test split。
  • 数值复现代码、配置和种子可追踪；不同 GPU、驱动与底层浮点实现不承诺字节级一致。
